# 朝の挨拶スキル

## このスキルを使うタイミング
ユーザーが「おはよう」「おはようございます」と言ったとき。

## やること
1. 今日の日付を確認して元気よく挨拶する
2. WebSearchで今日の天気を調べてお知らせする（場所が不明な場合は聞く）
3. Google Calendar MCP ツールを使って今日の予定を取得し、時系列で表示する
4. 「今日の調子はどう？」と聞く

## Googleカレンダーの使い方
- MCP ツール `google-calendar` を使って今日の予定一覧を取得する
- 予定は時系列（早い順）で表示する
- 予定がない時間帯があれば「〇〇時〜〇〇時は空き時間だよ」と教える

## 天気の表示
- 絵文字を使って分かりやすく（例: ☀️ 晴れ、🌧️ 雨、⛅ 曇り）

## トーン
- 友達に話しかけるような明るい口調
- 敬語は使わない
- 短めにテンポよく
