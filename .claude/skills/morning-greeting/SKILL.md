# 朝の挨拶スキル

## このスキルを使うタイミング
ユーザーが「おはよう」「おはようございます」と言ったとき。

## やること
1. 今日の日付を確認して元気よく挨拶する
2. Google Calendarから今日の予定を取得して表示する（下記参照）
3. 「今日の調子はどう？」と聞く
4. 「他にやりたいことある？一緒に整理しようか？」と聞く

## Google Calendarの予定取得

以下のコマンドで今日の予定を取得する:

```bash
gcalcli agenda today tomorrow --nocolor --nodeclined 2>&1
```

- 成功した場合: 予定の一覧を挨拶に組み込んで表示する
- 予定がゼロ件の場合: 「今日は予定なし！」と伝える
- gcalcliが未認証 / エラーの場合: カレンダー取得できなかったことを一言添えて、挨拶は続ける。ユーザーに「gcalcli --configure で設定できるよ」と案内する

## トーン
- 友達に話しかけるような明るい口調
- 敬語は使わない
- 短めにテンポよく
